# Case brief template

Copied into `investigations/<case-id>/case.md` at intake.

```markdown
# Case <case-id>

## Intake
- Subject:
- Disambiguation (what identifies this subject uniquely):
- Investigation question:
- Timeframe:
- Jurisdiction:
- Intended use: personal decision / research memo / public-facing report
- Initial hypothesis (UNVERIFIED):
- Supplied materials:

## Neutral brief
One paragraph, no conclusions.

## Scope
- In scope:
- Out of scope:

## Plan
- Questions to answer:
- Likely primary sources:
- Modules to run (and any skipped, with reason):
- Evidence gaps:
- Privacy / legal sensitivities:

## Claims
| ID | Claim (exact quote or labeled paraphrase) | Kind (fact / promise / opinion / implied / allegation / formal finding) | Source |
|---|---|---|---|
```
