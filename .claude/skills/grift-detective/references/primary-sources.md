# Primary-source playbook

Start here before secondary coverage. A primary source is best evidence of what its author stated or filed. It is not automatically true.

| Question | Where to look |
|---|---|
| Public company filings, risk factors, related-party deals | SEC EDGAR (sec.gov/edgar) |
| Lawsuits, dockets, judgments | CourtListener / RECAP (courtlistener.com), PACER, state court portals |
| Regulatory actions, consent orders, warnings | FTC, CFPB, SEC litigation releases, CFTC, FINRA BrokerCheck, state attorney-general press releases |
| Corporate entities, officers, registered agents | OpenCorporates, state Secretary of State registries |
| Nonprofit finances, officer pay | ProPublica Nonprofit Explorer (IRS Form 990) |
| Political money | FEC (fec.gov), OpenSecrets |
| Earlier versions or deleted pages | Wayback Machine (web.archive.org) |
| Domain age, hosting, ownership signals | WHOIS / RDAP, DNS history |
| Ad claims and spend | Meta Ad Library, Google Ads Transparency Center |
| App claims and complaints | App store listings; CFPB complaint database |
| Product or income claims | The subject's own sales page, terms, refund policy, earnings disclaimer |
| Customer experience (weak signal only) | BBB, Trustpilot, Reddit. Treat as leads, not findings. Reviews can be fake or selected |

## Notes
- Jurisdiction matters. Record which one each source covers.
- A filing shows what was filed, not that it is accurate.
- Absence in a database is not proof of absence. Say what you searched and when.
- An accusation, complaint or lawsuit is not a finding. Record the outcome if there is one.
